# TodoMVC in React, ported by Claude Haiku 5.5 and checked by Kane CLI

A second, independent port of the official [TodoMVC jQuery example](https://github.com/tastejs/todomvc/tree/master/examples/jquery), written by Claude Code running Haiku 5.5 with a 40-turn budget. [Ditto](https://github.com/itssaharsh/ditto) had Kane CLI replay the jQuery app's recordings on it: 18 of 18 behaviours the same, 22 of 24 Kane runs pure replays, 7.4 credits for the whole check.

The behaviour tests are in [`tests/kane/`](tests/kane).
